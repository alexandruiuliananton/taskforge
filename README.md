\# TaskForge



TaskForge is a workflow-driven task management system built with Clean Architecture using .NET.



\## 🚀 Features

\- Task management with controlled state transitions

\- Workflow-based logic (ToDo → InProgress → Done)

\- Clean Architecture (Domain, Application, Infrastructure, API)

\- Extensible for automation rules and integrations



\## 🧱 Architecture



\- \*\*Domain\*\* – core business logic and rules

\- \*\*Application\*\* – use cases and orchestration

\- \*\*Infrastructure\*\* – data access and external services

\- \*\*API\*\* – entry point (REST)



\## 🛠 Tech Stack



\- .NET Web API

\- xUnit (testing)

\- Azure (planned)

\- Angular (planned)
